## 🚀 One-Step Quick Installation

Clone and run the standalone installer on any Apple Silicon Mac:

```bash
git clone git@github.com:VanoStrey/neon-lattice.git
cd neon-lattice
./install.sh
```

*(Installation takes **0.1 seconds** because the precompiled ARM64 binary is ready out of the box).*

### Advanced Installation Options:

```bash
./install.sh                  # Install and start live wallpaper immediately (default)
./install.sh --autostart      # Install, start, and enable automatic launch on macOS login
./install.sh --no-start       # Install CLI and Mac App bundle only (without launching daemon)
./install.sh --build          # Force recompile from source using native swiftc compiler
./install.sh --uninstall      # Cleanly remove all binaries, App bundles, and LaunchAgents
```

## 🎮 How to Control

### 1. From Terminal (CLI):

```bash
neon-wallpaper status            # View real-time FPS, GPU/CPU usage, RAM, and active screens
neon-wallpaper stop              # Stop the live wallpaper daemon
neon-wallpaper start             # Start the live wallpaper in the background
neon-wallpaper toggle            # Toggle wallpaper on / off
neon-wallpaper autostart enable  # Enable autostart on system login (LaunchAgent)
neon-wallpaper autostart disable # Disable autostart on system login
neon-wallpaper uninstall         # Completely remove from system
```

### 2. From macOS GUI:

- **Spotlight Search**: Press <kbd>Cmd</kbd> + <kbd>Space</kbd>, type **`Neon Wallpaper`**, and hit <kbd>Enter</kbd> to toggle the wallpaper!
- **Finder / Launchpad**: Open `~/Applications/NeonWallpaper.app`.
- **System Settings**: Add `NeonWallpaper.app` to **System Settings $\to$ General $\to$ Login Items** for GUI-based autostart management.

## 🔬 Scientific & Physical Model

### 1. Gray-Scott Reaction-Diffusion

Morphogenetic pattern formation is governed by non-linear partial differential equations:

$$\frac{\partial u}{\partial t} = D_u \nabla^2 u - u v^2 + F (1 - u)$$
$$\frac{\partial v}{\partial t} = D_v \nabla^2 v + u v^2 - (F + k) v$$

- $u$: Inhibitor chemical concentration
- $v$: Activator chemical concentration (morphogen)
- $\nabla^2$: Discrete 9-point 2D Laplacian operator
- Regime: **Chaos / Turbulence** ($F = 0.0180, k = 0.0510, dt = 0.50$)

### 2. $N$-Body Gravitational Slingshot Dynamics

$$m_i \propto \left(\frac{r_i}{16.0}\right)^2$$
$$\vec{F}_{ij}^{\text{grav}} = G \cdot \frac{m_i m_j}{(d^2 + \epsilon^2)^{3/2}} \cdot \vec{r}_{ij} \cdot \text{fade}(d)$$
$$\vec{F}_{ij}^{\text{repel}} = -k_{\text{repel}} \cdot ((r_i + r_j) - d) \cdot \frac{\vec{r}_{ij}}{d} \quad \text{for } d < r_i + r_j$$
$$\vec{F}_i = \sum_{j \ne i} \vec{F}_{ij}, \quad \sum_k \vec{F}_k \equiv 0 \quad (\text{Newton's 3rd Law})$$
